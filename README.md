# Vivek Arya — Portfolio Site

Static portfolio for Vivek Arya, product builder who manages, designs and codes.

Images are self-hosted in `assets/img/` and served as `<picture>`: AVIF first,
then WebP, then PNG/JPG (generated by the CMS `optimize:images` script).

Live: https://vivekarya.vercel.app

## Structure

Plain static HTML/CSS/JS (originally a Webflow export). No build step — Vercel
serves the repo root as-is with clean URLs.

- `index.html`, `about.html`, `works.html`, `contact.html` — pages
- `projects/*.html` — case study pages
- `assets/` — CSS, JS, fonts, images (`services-anim.*` drive the services art)

## Content updates

Project cards, the featured list and `projects/*.html` are generated by the
private CMS. Publishing in the CMS triggers `.github/workflows/rebuild-site.yml`,
which regenerates those pages and commits them here; Vercel deploys the push.
